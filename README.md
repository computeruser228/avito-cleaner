
# Avito Cleaner: Reserved Ads

Расширение Chrome для фильтрации забронированных объявлений на Avito.

## Возможности

- Скрытие забронированных объявлений.
- Размытие объявлений вместо скрытия.
- Скрытие верхней панели категорий.
- Опциональное снятие размытия при наведении.

## Установка

1. Скачайте репозиторий через Code → Download ZIP.
2. Распакуйте архив.
3. Откройте chrome://extensions/.
4. Включите режим разработчика.
5. Нажмите «Загрузить распакованное расширение».
6. Выберите папку с manifest.json.
